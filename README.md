# 티코 캘린더 (Tico Calendar)

말티즈 "티모"와 요크셔테리어 "코코"가 함께하는, 프리랜서 강사를 위한 귀여운 일정 관리 캘린더입니다.
로그인 없이 브라우저에서 바로 사용할 수 있으며, 모든 데이터는 사용자의 브라우저(localStorage)에만 저장됩니다.

## 주요 기능

- 월간 캘린더 (일~토), 일정 등록/수정/삭제
- 카테고리(기념일/업무/개인) 색상 구분
- 강의 일정 전용 입력: 담당 기관명, 담당자 전화번호, 강의단가, 강의분류(직접 추가 가능)
- 강의 3일 전 / 1일 전 알림 (코코 캐릭터 말풍선)
- 브라우저 음성 인식(Web Speech API)으로 일정 등록
- 월별 강의단가 합산 예상 수입 자동 계산
- 일정 + 할 일 통합 메뉴 (할 일은 별도 탭에서 관리, 날짜 연결 가능)
- 담당자 전화번호 탭하면 바로 전화 연결(tel: 링크)

## 로컬 실행

```bash
npm install
npm run dev
```

## 프로덕션 빌드 & 실행

```bash
npm run build
npm run start
```

`server.js`는 빌드된 정적 파일(`dist/`)을 Express로 서빙하는 아주 작은 서버입니다.
앱 자체는 서버 없이 브라우저에서만 동작하며, 이 서버는 정적 파일 호스팅 용도로만 사용됩니다.

## Railway 배포

이 저장소에는 Railway 배포에 필요한 설정이 포함되어 있습니다.

- `railway.json`: 빌드 명령(`npm install && npm run build`)과 시작 명령(`npm run start`) 정의
- `Procfile`: `web: npm run start`
- `.nvmrc`: Node 20 사용

Railway에서 새 프로젝트를 만들고 이 저장소를 연결하면 자동으로 빌드/배포됩니다.
별도의 데이터베이스나 환경변수 설정이 필요하지 않습니다.

## 참고 사항

- 음성 인식은 Chrome 등 Web Speech API를 지원하는 브라우저에서만 동작합니다.
- 모든 데이터는 브라우저 로컬 저장소에만 저장되며, 다른 기기/브라우저와 동기화되지 않습니다.
